"Neon Tides: Solmaris" — an original open-world crime game in the browser (Three.js): play courier Dario Solano in the neon coastal city of Solmaris — roam on foot, steal and drive cars, run a 3-mission story chain for fixer Lucia Ferran, outrun Capt. Reyes's police as your wanted stars rise, and fight Vex Marlowe's crew. Controls: WASD + mouse, E enter/exit car, click to shoot, Shift run, Esc pause. Progress saves in the browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
